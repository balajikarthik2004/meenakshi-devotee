# Cafeteria dish photographs

One photograph per dish on the board. Sourced from Wikimedia Commons at 480px,
the width the menu card's thumbnail strip actually needs. Nothing here is scraped
from meenakshi.org or any other temple site.

Each was checked against the dish it illustrates. An automated first pass matched
a goat-masala photograph to the spiced buttermilk and a Dutch shopfront to the
bonda — on a vegetarian temple's page the first is unacceptable and the second is
absurd — so matching requires the dish's own name in the Commons file title,
rejects any title carrying a meat word, and the results were reviewed by eye.
